# 寿司打ちタイピング大会

北九州ITクラブ「まんまる文化祭」（2026/11/21-22）出し物用のタイピングゲームです。
GitHub Pagesにそのままアップロードするだけで動きます（サーバー不要・静的ファイルのみ）。

## 遊び方（参加者）

1. `index.html` を開く
2. 名前（ニックネームでもOK）と年齢層を選ぶ
   - 小学生（低学年／高学年）、中学生、高校生、大学生、その他（実年齢を入力）
3. 制限時間（60/90/120秒）を選んでスタート
4. 表示された寿司ネタをローマ字でタイピング（例：まぐろ → maguro）
5. 制限時間内にできるだけ多くの「円」を稼ぐ！

結果（名前・年齢層・スコアなど）は自動的にブラウザに保存されます。

## 管理画面（admin.html）

画面右下の「admin」リンク、または直接 `admin.html` を開いてください。

- 初期パスワード： `itclub2026`（`admin.html` の「ゲーム設定」からいつでも変更できます）
- **成績データ**：参加者一覧の確認、CSVエクスポート（文化祭終了後の集計・分析用）
- **広告画像**：左右6枠ずつ、Instagram正方形画像などをアップロード可能（自動リサイズして保存）
- **ゲーム設定**：制限時間のデフォルト値、管理者パスワードの変更

## データの保存について（重要）

このアプリはサーバーを使わない「静的サイト」のため、参加者データ・広告画像・設定は
**遊んでいるブラウザ（端末）のlocalStorage** に保存されます。

- 文化祭当日は **同じ端末・同じブラウザ** で通し運用してください（途中で別のPCに変えるとデータが引き継がれません）
- 会場ではWiFiに接続していればGitHub Pagesとして問題なく動作します（オフラインでも一度読み込めば動作しますが、CSV出力等は端末内で完結します）
- 文化祭終了後は、その端末の `admin.html` からCSVをダウンロードしてバックアップしてください
- ブラウザのキャッシュ／サイトデータを削除するとデータが消えるのでご注意ください

## GitHubへのアップロード方法（このリポジトリごと）

1. このフォルダの中身（`index.html` / `admin.html` / `css/` / `js/` / `assets/`）をそのままGitHubリポジトリにアップロード
2. リポジトリの Settings → Pages で、公開ブランチ（例：`main`）とルート（`/`）を指定して保存
3. 発行されたURL（例：`https://<ユーザー名>.github.io/<リポジトリ名>/`）で公開されます

学生さんとの共同作業もしやすいよう、機能ごとにファイルを分けています。

```
sushi-typing-game/
├── index.html        ... ゲーム画面
├── admin.html         ... 管理画面
├── css/
│   └── style.css      ... デザイン（配色は北九州ITクラブのロゴを参照）
├── js/
│   ├── words.js        ... 寿司ネタの単語データ（ここに追加・編集すると出題内容を変更できます）
│   ├── storage.js      ... localStorage/CSV/画像リサイズ等の共通処理
│   ├── game.js          ... ゲーム画面のロジック
│   └── admin.js          ... 管理画面のロジック
└── assets/
    └── itclub-logo.jpg  ... ヘッダーに表示するロゴ
```

## カスタマイズしたいとき

- **出題される寿司ネタを増やしたい** → `js/words.js` の `SUSHI_ITEMS` に追加（かな表記／ローマ字表記（複数可）／値段）
- **配色を変えたい** → `css/style.css` 冒頭の `:root` 内のCSS変数（`--club-blue` 等）を変更
- **ランクのコメントを変えたい** → `js/words.js` の `RANKS` を編集

## 免責事項

管理画面のパスワードチェックはブラウザ内だけの簡易的なものです（ソースコードを見れば分かってしまいます）。
文化祭のような身内イベントでの簡易的な運営者向け機能として設計しており、厳密なセキュリティが必要な用途には適していません。
